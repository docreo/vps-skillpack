# Start Here

The FREE VPS SkillsPack is organized as a practical build sequence.

## Build order

1. Prepare the VPS baseline.
2. Install and test Hermes Agent.
3. Bring up the dashboard and Kanban board.
4. Configure a model provider and test model routing.
5. Create specialist agent profiles.
6. Add MCP or other tool connections.
7. Add GHL only if you use it for business operations.
8. Schedule one useful recurring task.
9. Verify results instead of relying only on an agent saying a task is complete.
10. Turn the accepted setup into a reusable template.

## Success target

At the end of the pack, you should have a VPS where an AI agent can receive work, route tasks to specialist profiles, use connected tools, complete scheduled jobs, and leave enough evidence for you to verify what happened.

## Important scope note

This is a public skills pack, not a copy of a private production environment. Use vendor documentation for current installation, networking, account, compliance, and security requirements.

Start with `skills/01-VPS-BASELINE.md`.
