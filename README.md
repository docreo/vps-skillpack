# FREE VPS SkillsPack

A public learning pack for building a practical AI operations environment on a VPS.

This pack is designed for people who want to move from a basic Linux VPS to a working AI operations setup with:

- Hermes Agent
- a dashboard and Kanban task board
- multiple specialist profiles
- model and provider selection
- MCP and tool connections
- optional GHL business integration
- scheduled jobs
- functional verification
- a reusable VPS deployment template

The pack intentionally focuses on reproducible public build knowledge. It does not include private repositories, private build history, internal infrastructure, customer information, credentials, proprietary security architecture, or internal Signalproof operating procedures.

## Start here

Open `00-START-HERE.md` and work through the skills in order.

## What you need

- a Linux VPS you control
- shell access to that VPS
- Git and curl
- at least one supported AI model provider or local model endpoint
- optional accounts for any business tools you want to connect
